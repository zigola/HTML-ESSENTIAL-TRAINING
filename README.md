# HTML Essential Training

A hands-on HTML5 learning path focused on semantic markup, accessible structure, forms, navigation, and maintainable frontend foundations.

## Learning outcomes

- Build valid, semantic HTML documents
- Structure headings, landmarks, lists, tables, and links correctly
- Create accessible forms with labels and useful validation
- Use images responsibly with meaningful alternative text
- Understand metadata, document language, and basic SEO
- Prepare clean HTML for CSS and JavaScript enhancement

## Suggested learning path

1. **Document foundations** — doctype, language, head, title, metadata, and body.
2. **Semantic content** — headings, sections, articles, navigation, and footer.
3. **Links and media** — paths, images, captions, and accessible descriptions.
4. **Forms** — labels, input types, fieldsets, and validation.
5. **Tables and data** — captions, headers, and logical reading order.
6. **Accessibility review** — keyboard use, focus visibility, contrast, and screen-reader structure.

## Exercises

Create a separate folder for each exercise. Keep each example small, readable, and easy to review.

| Exercise | Deliverable |
| --- | --- |
| Personal profile | Semantic single-page profile |
| Article page | Article with clear heading hierarchy |
| Contact form | Labeled and keyboard-accessible form |
| Data table | Table with caption and header associations |
| Portfolio landing page | Responsive-ready HTML structure |

## Validate your work

HTML files can be opened directly in a browser. For a more reliable review, use the W3C Nu HTML Checker:

- https://validator.w3.org/nu/

Before submitting an exercise, check:
- [ ] The document declares its language.
- [ ] There is one clear page-level heading.
- [ ] Heading levels follow a logical order.
- [ ] Every form control has an associated label.
- [ ] Images have appropriate alternative text.
- [ ] Links describe their destination.
- [ ] The page works with keyboard navigation.

## Repository status

This is a learning repository. Exercises and examples should be added progressively; the learning goals above are not a claim that every exercise is already implemented.

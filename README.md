# HTML Essential Training

A practical learning repository for building a strong foundation in HTML5, semantic markup, accessible page structure, forms, and essential frontend development concepts.

## Learning goals

- Write clean and meaningful HTML structure
- Understand semantic elements and document hierarchy
- Practice accessible forms and navigation
- Build maintainable foundations for CSS and JavaScript

## Status

This repository is a learning project and will grow through exercises, examples, and documented improvements.
